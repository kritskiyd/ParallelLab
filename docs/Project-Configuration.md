Системные Title, Assignees, Parent issue, Sub-issues progress и элементы оболочки GitHub остаются техническими. Дублирующие поля для перевода не создавались.

## Автоматизации

Сохранены восемь включённых правил; их названия переведены без изменения действий и идентификаторов. Названия недействующих встроенных шаблонов и служебные подписи редактора остаются частью оболочки GitHub. Эти шаблоны не включались ради перевода.

| Правило | Условие и действие |
| --- | --- |
| Добавление открытых задач | Открытая Issue ParallelLab по `is:issue is:open` добавляется в проект |
| Добавление дочерних задач | Дочерняя Issue включается в проект родителя |
| Начальный статус задачи | Новый элемент получает «Бэклог» |
| Статус закрытой задачи | Элемент получает «Выполнено» |
| Начало работы по запросу на слияние | Связанная Issue получает «В работе», а не «Выполнено» |
| Статус объединённого запроса | Элемент запроса на слияние получает «Выполнено»; это не приёмка всех родительских функций |
| Закрытие задачи по статусу | Перевод Issue в «Выполнено» закрывает её только при осознанном соблюдении условий завершения |
| Возврат переоткрытой задачи | Issue возвращается в «Бэклог» |

Идентификаторы опций сохранены. После перевода проверяются назначения правил и фильтры. Автоархивирование не включалось. Не создавались фиктивные завершения и слияния для проверки правил. Автодобавление проверено на реальных новых технических задачах.

## Проверка и ограничения

После добавления подготовительного этапа проверены 94 реальных Issue и 83 нативные родительские связи в обоих направлениях. Все 94 Issue включены в существующий проект. Исходные #1–#83 остаются открытыми. Закрыты только #85–#92, подтверждённые существующими результатами. Всего 86 открытых и 8 закрытых Issues; организационный родитель #84 находится в работе и не получает отдельную итерацию. #93 находится на проверке, #94 готова к работе. Ни одна пользовательская функция не объявлена реализованной по факту готовности макета.

Все 94 строки штатного экспорта сверены с назначениями, статусами, выпусками, оценками и родителями; расхождений нет. В поле «Спринт» назначен 61 элемент; 53 оценки историй сохранены. Проверены 93 относительные ссылки, полнота 31 истории MVP, отсутствие циклов и порядок зависимостей. Внутри одного спринта зависимые задачи выполняются последовательно.

Приватность проекта и репозитория сохранена. Восемь автоматизаций переиспользованы. Действующий вход Git не предоставляет права API Projects; поля, итерации и статусы настраиваются через браузер, без расширения прав. Не выдумывались согласование макета, ответы на открытые вопросы и фактические замеры производительности.
