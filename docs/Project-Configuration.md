# Настройка GitHub Project

## Существующие объекты

[ParallelLab: разработка по Scrum](https://github.com/users/kritskiyd/projects/1) является тем же проектом № 1, ранее называвшимся ParallelLab Scrum Development. [Репозиторий](https://github.com/kritskiyd/ParallelLab) и проект остаются приватными. Основной репозиторий проекта не менялся. Номера 73 исходных Issues и существующие родительские связи сохранены. Добавлены только десять технических проверок существующих функций: #74–#83.

## Поля и представления

Существующие поля переименованы без пересоздания: Priority → «Приоритет», Story Points → «Оценка сложности», Iteration → «Спринт», Release → «Выпуск», неиспользуемое Size → «Размер задачи». Поле размера скрыто и не заменяет числовую оценку. Значения приоритетов P0/P1/P2 сохранены для сортировки. Выпуски: «Первый выпуск (MVP)», «Второй выпуск», «Третий выпуск».

Имя системного Status GitHub не разрешает менять; его значения переведены: «Бэклог», «Готово к работе», «В работе», «На проверке», «Выполнено». Системные Title, Assignees, Parent issue, Sub-issues progress и элементы оболочки GitHub остаются техническими. Дублирующие поля для перевода не создавались.

| Представление | Назначение |
| --- | --- |
| Текущий спринт | Доска по статусам; фильтр `спринт:@current` |
| Следующий спринт | Доска по статусам; фильтр `спринт:@next` |
| Бэклог продукта | Таблица всех Issues, сортировка по приоритету по возрастанию |
| План разработки | План по полю «Выпуск», фильтр `label:история`, даты начала и окончания поля «Спринт» |
| На проверке | Фильтр `status:"На проверке"` |
| Мои задачи | Задачи назначенного текущего пользователя; отсутствие назначений не является ошибкой |

В таблице сохранены название, исполнитель, статус, приоритет, оценка, спринт, выпуск и родитель. Все элементы являются реальными Issues, черновики не создавались. Ассигнования не выдумывались.

## Спринты и оценки

В том же поле находятся 12 интервалов по 14 дней: 20.10.2026–05.04.2027. Первые восемь интервалов сохранены, добавлены следующие четыре. Все 31 история первого выпуска и 20 технических задач распределены по спринтам. 22 истории будущих выпусков оставлены без дат. Отдельных оценок у разделов и технических частей нет: иначе трудоёмкость считалась бы дважды.

Текущий спринт содержит подготовительные #64, #71 и #72. Следующий содержит #11–#13, #65–#70 и #73. Даты являются планом, праздники и загрузка проверяются при планировании. Описание цели итерации хранится в [плане](Sprint-Planning.md), поскольку отдельного редактора цели в поле нет.

## Автоматизации

Сохранены восемь включённых правил; их названия переведены без изменения действий и идентификаторов. Названия недействующих встроенных шаблонов и служебные подписи редактора остаются частью оболочки GitHub. Эти шаблоны не включались ради перевода.

| Правило | Условие и действие |
| --- | --- |
| Добавление открытых задач | Открытая Issue ParallelLab по `is:issue is:open` добавляется в проект |
| Добавление дочерних задач | Дочерняя Issue включается в проект родителя |
| Начальный статус задачи | Новый элемент получает «Бэклог» |
| Статус закрытой задачи | Элемент получает «Выполнено» |
| Начало работы по запросу на слияние | Связанная Issue получает «В работе», а не «Выполнено» |
| Статус объединённого запроса | Элемент запроса на слияние получает «Выполнено»; это не приёмка всех родительских функций |
| Закрытие задачи по статусу | Перевод Issue в «Выполнено» закрывает её только при осознанном соблюдении условий завершения |
| Возврат переоткрытой задачи | Issue возвращается в «Бэклог» |

Идентификаторы опций сохранены. После перевода проверяются назначения правил и фильтры. Автоархивирование не включалось. Не создавались фиктивные завершения и слияния для проверки правил. Автодобавление проверено на реальных новых технических задачах.

## Проверка и ограничения

21.10.2026 выполнена независимая сверка REST/GraphQL и штатного экспорта таблицы после загрузки проекта. Подтверждены 83 открытые Issue: 10 разделов, 53 истории, 20 задач. Все 83 включены в существующий проект; 73 нативные родительские связи проверены в обоих направлениях. Все 83 строки экспорта соответствуют плану по названиям, статусам, приоритетам, выпускам, оценкам, спринтам и родителям. 53 оценки сохранены, 51 назначение спринта заполнено, расхождений нет. Все статусы: «Бэклог». Проверены 85 относительных ссылок документации; отсутствующих файлов нет. Циклов зависимостей и зависимостей от более поздних спринтов не обнаружено. Внутри одного спринта сохраняется последовательность зависимых задач.

После повторной загрузки текущая доска показывает 3 задачи, следующая 10 задач и оценку историй 13. План разработки показывает 53 истории; поля дат привязаны к началу и окончанию «Спринта». Убраны искусственные ограничения накопительной колонки «Бэклог» обеих досок. Восемь активных автоматизаций проверены по конфигурации после переименования, без фиктивных закрытий.

Действующий вход Git даёт доступ к репозиторию и Issues, но не предоставляет права API Projects. Права не расширялись: редактирование полей, представлений и итераций выполнено через браузер. Отсутствие локального GitHub CLI не мешает REST API, Git и браузеру. Системные элементы GitHub и ограничения уточнения требований не выдаются за выполненную разработку.
