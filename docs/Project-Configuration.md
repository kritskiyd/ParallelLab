# Настройка GitHub Project

## Доска разработки

[ParallelLab: разработка по Scrum](https://github.com/users/kritskiyd/projects/1) используется для планирования и контроля задач [репозитория](https://github.com/kritskiyd/ParallelLab). Проект и репозиторий приватные.

Задачи связаны по схеме «функциональный раздел → пользовательская история → техническая задача». Анализ продукта и разработка макета выделены в отдельный подготовительный этап [#84](https://github.com/kritskiyd/ParallelLab/issues/84).

## Поля

| Поле | Назначение |
| --- | --- |
| Title | Название задачи |
| Assignees | Исполнители |
| Status | Бэклог, Готово к работе, В работе, На проверке, Выполнено |
| Приоритет | P0: высокий, P1: средний, P2: низкий |
| Оценка сложности | Предварительная оценка пользовательской истории в условных единицах |
| Спринт | Двухнедельный интервал выполнения задачи |
| Выпуск | Первый выпуск (MVP), Второй выпуск, Третий выпуск |
| Parent issue | Родительская задача |
| Sub-issues progress | Прогресс дочерних задач |

Поле «Размер задачи» скрыто. Для оценки используется числовое поле «Оценка сложности».

## Представления

| Представление | Назначение |
| --- | --- |
| Все спринты | Основная доска по статусам с боковым списком спринтов; фильтр `has:спринт` |
| Бэклог продукта | Таблица всех задач, отсортированная по приоритету |
| План разработки | План по выпускам; фильтр `label:история`, даты определяются полем «Спринт» |
| На проверке | Задачи с фильтром `status:"На проверке"` |
| Мои задачи | Задачи, назначенные текущему пользователю |

Во вкладке [«Все спринты»](https://github.com/users/kritskiyd/projects/1/views/7) слева показаны названия, даты и количество задач всех 13 спринтов. Чтобы открыть нужный спринт, достаточно выбрать его в списке. Карточки распределены по статусам и показывают приоритет, оценку сложности и родительскую задачу. В заголовках колонок указаны количество задач и сумма оценок.

В спринты включён 61 элемент: 31 история MVP, 20 задач реализации и 10 подготовительных задач. Функциональные разделы и родитель подготовительного этапа не включаются в спринты, чтобы не дублировать дочернюю работу. Истории следующих выпусков пока не имеют дат.

## Спринты и оценки

План включает 13 спринтов по 14 дней с 20.10.2026 по 19.04.2027. Сроки предварительные и уточняются при планировании.

Первый спринт посвящён анализу и макету: выполнены 8 задач, 1 находится на проверке и 1 готова к работе. Во втором запланированы формат эксперимента, основа рабочей области и единый контекст текущего эксперимента. Цели и состав каждого спринта приведены в [плане](Sprint-Planning.md).

Оценены 53 пользовательские истории. Суммарная оценка 31 истории MVP составляет 126 единиц. Технические задачи входят в оценку родительских историй и отдельно не суммируются. Подготовительные задачи учитываются по результатам и статусам без отдельной оценки сложности.

## Автоматизации

В проекте включены восемь правил:

| Правило | Условие и действие |
| --- | --- |
| Добавление открытых задач | Открытые задачи репозитория по фильтру `is:issue is:open` добавляются в проект |
| Добавление дочерних задач | Дочерняя задача включается в проект родителя |
| Начальный статус задачи | Новый элемент получает статус «Бэклог» |
| Статус закрытой задачи | Закрытая задача получает статус «Выполнено» |
| Начало работы по запросу на слияние | Связанная задача переходит в статус «В работе» |
| Статус объединённого запроса | Объединённый запрос на слияние получает статус «Выполнено» |
| Закрытие задачи по статусу | Перевод задачи в «Выполнено» закрывает её |
| Возврат переоткрытой задачи | Переоткрытая задача возвращается в «Бэклог» |

Перед переводом в «Выполнено» нужно проверить критерии приёмки. Завершение одной технической задачи не означает готовность всей родительской истории. Автоархивирование отключено.
