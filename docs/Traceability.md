# Трассировка требований

## Использованные материалы

Оригиналы прочитаны локально без изменения: `Критский СД  УЖЦ ПО.docx` (POA, разделы 2 и 3) и `ParallelLab_User_Story_Map.drawio` из каталога дисциплины. Роли пользователей взяты из пункта 1.2, границы выпусков из раздела 2. Последняя карта содержит десять действий, в отличие от более раннего варианта с одиннадцатью. Использована именно актуальная структура.

Figma-прототип существует в прежнем проекте; в этой лабораторной он не изменяется. Сценарий прототипирования и его границы взяты из раздела 3 отчёта. Макет не является свидетельством реализации компилятора или вычислительного backend.

M03 является декомпозицией основного сценария и существующей рабочей области, а не новой продуктовой функцией. Карточка выбора Sequential/OpenMP/MPI разделена на самостоятельные проверяемые истории. Повторяющиеся подписи режимов и запуска не превращены в дублирующие требования: выбор режима, преобразование и выполнение имеют разные результаты.

## Проверка согласованности

CUDA-транслятор / CPU остаётся в MVP, Native / GPU в Version 1. Профили и удалённое выполнение остаются в Version 2. Доли портретов и данные экранов не используются как фактические метрики выполненной разработки.
