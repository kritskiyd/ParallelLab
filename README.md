# Учебно-исследовательская среда параллельных вычислений

Проект по теме «Разработка учебно-исследовательской среды параллельных вычислений для подготовки специалистов атомной отрасли».

Автор: Критский С. Д., группа 1-46М. Дисциплина: «Управление жизненным циклом программного обеспечения».

Среда объединяет работу с исходным кодом, подготовку и выполнение вычислительных экспериментов и анализ результатов. Основной объект продукта: вычислительный эксперимент. Технологии: Sequential C++, OpenMP, MPI и CUDA.

## Состояние проекта

Подготовлены требования, кликабельный прототип и организация Scrum-процесса. Этот репозиторий содержит документацию и шаблоны разработки. Реализация исполняемого продукта пока не добавлена. Наличие Issue, оценки или спринта не означает завершение функции.

MVP предусматривает выполнение поддерживаемого CUDA-кода на CPU через CUDA-транслятор. CUDA Native на NVIDIA GPU относится к Version 1. Время CPU-режима не является оценкой производительности GPU.

## Пользовательский сценарий

Эксперимент → исходный код → технология → параметры → проверка окружения → одиночный запуск или серия → сохранённые результаты → сравнительный анализ.
