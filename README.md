# ParallelLab

Учебно-исследовательская среда параллельных вычислений для подготовки специалистов атомной отрасли. Автор: Критский С. Д., группа 1-46М.

В репозитории организованы процесс разработки и требования. Это не утверждение о наличии готового вычислительного приложения. Существующий интерактивный прототип показывает пользовательский сценарий и служит основой интерфейса; отчёт по дисциплине не является частью приложения.

## Работа над продуктом

[Доска разработки](https://github.com/users/kritskiyd/projects/1) · [Задачи](https://github.com/kritskiyd/ParallelLab/issues) · [Документация](docs/Home.md)

10 функциональных разделов, 53 пользовательские истории и 20 технических задач. Первый выпуск включает 31 историю с общей предварительной оценкой 126 условных единиц. План: 12 двухнедельных спринтов. Назначение спринта не означает выполнение; закрытие только после реализации и проверки.

Основной путь: эксперимент → код → технология → параметры → окружение → запуск / серия → результаты → анализ.

## Границы первого выпуска

Sequential C++, OpenMP, MPI и выполнение поддерживаемого CUDA-кода через CUDA-транслятор на CPU. Для CPU-режима NVIDIA GPU не обязательна, но требуются транслятор и C++17 компилятор. Этот режим не измеряет производительность GPU.

CUDA Native и расширенный экспорт относятся ко второму выпуску. Совместная работа, удалённые ресурсы и расширенная аналитика относятся к третьему. Среда не является системой управления АЭС или реактором.
